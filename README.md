# Shift Maker Personal

個人用のシフト入力カレンダー。GitHub Pagesで動く、ビルド不要の静的サイトです。

- 日付の複数選択と一括入力
- 早番（09:30–19:00）、遅番（11:00–20:45）、休み、Free
- 任意の時間指定、翌日にまたがるシフト
- 毎月11日〜翌月10日の期間切り替え、ブラウザ内への自動保存
- JSONバックアップの書き出し・読み込み

ログイン・API・データベース・環境変数は不要です。元のNext.jsアプリから、入力機能だけを独立させています。

## データの保存

シフトはlocalStorageに保存します。同じ端末・ブラウザ・サイトURLで開くと復元されます。端末間の同期はありません。プライベートブラウズやブラウザデータ削除で消えることがあるため、定期的に「書き出す」を使ってください。読み込みは全件を置き換えます。

サイト自体は公開URLから誰でも開けますが、シフトデータをサーバーへ送信する処理はありません。共有端末では、同じブラウザを利用する人が保存データを閲覧できる点に注意してください。GitHub Pagesは同じドメインでlocalStorageを共有するため、同一アカウントの他のPagesサイトとも保存領域を共有します。

## GitHub Pages

このフォルダ内のファイルを `gh-pages` ブランチの直下に配置し、GitHubの Settings → Pages → Deploy from a branch → gh-pages / (root) を選択します。元のmainブランチは変更不要です。

## ローカルで確認

このフォルダで `python3 -m http.server 8000` を実行し、http://localhost:8000 を開きます。ES Modulesを使うため、HTMLファイルの直接ダブルクリックではなくHTTP経由で開いてください。

表示する期間は開始月で指定します（例: 2026年10月 → 10月11日〜11月10日）。初期表示は今日を含む期間です。保存データの形式は以前と同じで、既存の入力を引き継ぎます。
